Clipfinder

Clipfinder is a personal desktop tool. It edits gaming highlight clips into vertical short videos and posts them to the owner's own TikTok and YouTube accounts using the official TikTok Content Posting API and the YouTube Data API.

It is not a public service. Only the owner signs in, and only the owner's accounts are used. The original creator of each clip is credited by name in the video description.
